# 山林お引き取り 書類作成ツール

お客様情報・金額・土地を1回入力すると、次の5つの書類を差し込み済みの Word ファイルで作成します。

1. 同意書（兼お申込み書）
2. 見積書送付のご案内
3. 山林引き取り契約書
4. 契約書送付のご案内
5. 請求書

土地の所在は、ハザード自動判定ツールと同じく「頭文字 → 都道府県 → 市区町村 → 町名」の順で選べます。

## 公開の手順（Streamlit Community Cloud）

1. GitHub で新しいリポジトリ（例：`sanrin-docs`）を作り、このフォルダの中身をすべてアップロードします。
   - `templates` フォルダと `.streamlit` フォルダも含めてください。
2. https://share.streamlit.io を開き、「Create app」から、そのリポジトリと `app.py` を選んでデプロイします。
3. アプリの「Settings → Secrets」に、`secrets_sample.toml` の内容を公式LINEのIDに書き換えて貼り付けます。
   - 登録しない場合は、画面の「会社設定」で毎回入力できます。

> お客様の個人情報を扱うため、公開範囲は「Settings → Sharing」で、自分だけ（または社内の人だけ）が開ける設定にしてください。

## 書類の文面を変えたいとき

`templates` フォルダの Word ファイルを直接編集して、上書きアップロードします。
`{{氏名}}` のような `{{ }}` の部分が差し込まれる場所です。

- 文字を直すときは、`{{ }}` の中の文字を消したり分けたりしないでください。
- 土地の表は、1行目（`{{土地所在地1}}` の行）を見本にして、筆の数だけ行が増えます。

## 使える差し込み項目

| 項目 | 変数 |
|---|---|
| お客様 | 受付番号、氏名、氏名フリガナ、郵便番号、住所、電話番号、メールアドレス |
| 金額・期限 | 見積金額、支払期限、請求番号、備考 |
| 日付（令和） | 作成年・作成月・作成日、請求年・請求月・請求日 |
| 土地（1筆ごとに番号） | 土地所在地1、地番1、地目1、地積1、持分1 …… |
| 会社 | 公式LINE_ID |
